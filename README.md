# EZproxy stanzas

Konfigurace (stanzas) EZproxy, které nejsou k dispozici na [OCLC EZproxy Database Stanzas](https://help.oclc.org/Library_Management/EZproxy/EZproxy_database_stanzas/Database_stanzas).

Jednotlivé konfigurace se nachází v adresáři _stanzas_, každá konfigurace v jednom souboru. 

> [!NOTE]
> Některé konfigurace nelze použít jen pouhým překopírovaním a je nutné je dokonfigurovat. Instrukce jsou přímo v jendotlivých souborech daných konfigurací.

Kontakt a dotazy: [Vlastimil Krejčíř, ÚVT MU](https://www.muni.cz/lide/4189-vlastimil-krejcir)
